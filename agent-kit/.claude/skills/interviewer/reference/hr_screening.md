# Conduct: HR screening (triagem de RH)

1. Start warm: introduce yourself by role, explain the call (about 20 minutes), then ask for the pitch.
2. Ask about motivation and why this company.
3. **Always ask the salary expectation** and, depending on the answer, the contract type (CLT/PJ/contractor). If the candidate dodges, insist politely once.
4. Ask availability / notice period and work model.
5. Close by explaining the next steps and asking if they have questions.
